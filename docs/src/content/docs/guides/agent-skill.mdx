An AI coding agent can write the pages of a Starlight site, but it does not know the attributes and directives of this plugin. The plugin comes with an agent skill: a set of instructions in the [Agent Skills](https://agentskills.io) format. Claude Code, Codex, Cursor, GitHub Copilot and many other agents read this format. With the skill, an agent can pick the right feature for each code block and write its syntax correctly.

## Install the skill

Run this command in the folder of the site:

```sh
npx skills add ewels/starlight-codeblocks
```

The [skills CLI](https://github.com/vercel-labs/skills) finds the coding agents that you use. It installs the skill into the skills folder of each agent in the project, such as `.claude/skills/` for Claude Code or `.agents/skills/` for Codex.

To give the skill to one agent without the questions, name the agent:

```sh
npx skills add ewels/starlight-codeblocks --agent claude-code --yes
```

Add `--global` to install the skill for every project on your computer. Run `npx skills update` to get a new version of the skill.

An agent without a skills folder can read the skill from the text of this page. Point it at the [Markdown version](/starlight-codeblocks/guides/agent-skill.md) of the page.

## What the skill covers

The skill is short, so it costs an agent little context. The agent reads `SKILL.md` first. It reads a reference file only when a task needs the features in it.

- `SKILL.md` gives the set-up and the syntax rules for attributes and directives. For each sidebar group, a table goes from a goal to the feature for it. A list gives the mistakes to avoid.
- Each reference file covers one sidebar group. For each feature, it gives what the feature is for, when not to use it, its attributes, directives and options, an example and its limits.
- `references/configuration.md` gives every option, the set-up with `ec.config.mjs`, and the set-up next to other plugins.

A test in the repository fails if a feature, an attribute, a directive or an option is missing from the skill. This page shows the skill files themselves, so the text below is always the current skill.
