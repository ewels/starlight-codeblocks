Starlight renders every code block with Expressive Code. The plugin adds 24 features to those code blocks, such as focus, line states, annotations, links to API docs and runnable examples. Each feature starts when a code block uses its attribute or its directive, so existing pages do not change.

This block uses two features together. The fence line focuses line 9, and a directive in the comment adds an annotation. Hover over the block, or move keyboard focus into it, to see every line sharp. Select the number to read the note.

```js title="astro.config.mjs" focus={9} apiLinks=false
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';
import codeblocks from 'starlight-codeblocks';

export default defineConfig({
  integrations: [
    starlight({
      title: 'My docs',
      plugins: [codeblocks()], // [!annotate] One line turns on every feature. A feature changes a block only when the block uses it.
    }),
  ],
});
```

## Install

Add the package to the site:

:::code-switcher{sync="pm"}
```sh label="npm"
npm install starlight-codeblocks
```
```sh label="pnpm"
pnpm add starlight-codeblocks
```
```sh label="Yarn"
yarn add starlight-codeblocks
```
:::

Then add `codeblocks()` to the Starlight plugins in `astro.config.mjs`, as in the block above. The [getting started](/starlight-codeblocks/getting-started/) page has the full steps.

## Features

- [Comment notation](/starlight-codeblocks/features/comment-notation/): the directives in code comments that many features read.
- [Draw attention](/starlight-codeblocks/features/focus/): focus and line states.
- [Explain code](/starlight-codeblocks/features/annotations/): annotations, footnotes, inline callouts and notes beside the code.
- [Connect prose and code](/starlight-codeblocks/features/code-mentions/): links from the prose to lines, and code that follows the prose as readers scroll.
- [Show changes](/starlight-codeblocks/features/word-level-diff/): changed words in diffs, and code that changes in steps.
- [Shorten long code](/starlight-codeblocks/features/hidden-lines/): hidden lines and blocks that expand.
- [Make code easier to read](/starlight-codeblocks/features/visible-whitespace/): visible whitespace, bracket pair colours and syntax colours for inline code.
- [Add links](/starlight-codeblocks/features/token-links/): links on tokens, links to API docs and links to lines.
- [Adapt to the reader](/starlight-codeblocks/features/code-switcher/): variants of a block, and fields that readers fill in.
- [Copy and run](/starlight-codeblocks/features/smart-shell-copy/): copy without prompts, playground buttons and code that runs in the browser.
- [Extend](/starlight-codeblocks/extend/write-an-api-link-adapter/): your own API link adapters, playgrounds and runtimes.
- [Reference](/starlight-codeblocks/reference/options/): every option, attribute, directive and style setting.
