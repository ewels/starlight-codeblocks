A full file is sometimes the clearest example, but a reader scanning the page does not need every line in view at once. The `expandable` attribute caps the block at a line count, with a fade at the cut and a button that reveals the rest.

export const basic = `
\`\`\`py title="report.py" expandable={8} apiLinks=false
import csv
import sys
from collections import Counter
from pathlib import Path


def read_rows(path: Path) -> list[dict]:
    with path.open() as fh:
        return list(csv.DictReader(fh))


def summarise(rows: list[dict]) -> Counter:
    return Counter(row["status"] for row in rows)


def main() -> None:
    rows = read_rows(Path(sys.argv[1]))
    counts = summarise(rows)
    for status, n in counts.most_common():
        print(f"{status:<10} {n:>5}")


if __name__ == "__main__":
    main()
\`\`\`
`;

The block shows its first eight lines, faded at the bottom, with "Show all 24 lines" underneath. Selecting the button reveals the rest, and the button then reads "Show fewer lines".

## Syntax

| Syntax | Where | Example |
|---|---|---|
| `expandable` | Fence line | Caps the block at the site default, 12 lines |
| `expandable={N}` | Fence line | `expandable={8}` |

## Behaviour

- The block shows the first `N` lines, with a fade over the last one.
- A bar under the code has a button, "Show all X lines", where X is the total. After expanding, it reads "Show fewer lines".
- A block only collapses if doing so hides at least three lines. A block with eight lines and `expandable={7}` renders in full.
- The collapsed lines use `hidden="until-found"` in browsers that support it. A reader who searches the page with Find still finds text inside them, and the block expands to show the match.
- Without JavaScript, the block renders in full, with no fade and no button.

## Options

| Option | Type | Default | Description |
|---|---|---|---|
| `expandable` | `false \| object` | on | Set to `false` to turn expandable blocks off. `expandable` and `expandable={N}` then have no effect. |
| `expandable.lines` | `number` | `12` | Lines to show on a block that has the bare `expandable` attribute. |

A site that mostly shows short snippets can lower the site default, so that only unusually long blocks collapse:

```js title="astro.config.mjs"
codeblocks({
  expandable: { lines: 20 },
});
```

## Limitations

- Expandable blocks print in full: the fade and the button do not appear on paper.
- A [line permalink](/starlight-codeblocks/features/line-permalinks/) to a collapsed line does not open the block on page load. It opens only when the reader's browser runs its own Find and matches text inside the block.

## Related

- [Hidden lines](/starlight-codeblocks/features/hidden-lines/): remove specific lines from view, instead of capping the block at a line count.
- [Focus](/starlight-codeblocks/features/focus/): keep every line in view, and blur the ones that do not matter.
