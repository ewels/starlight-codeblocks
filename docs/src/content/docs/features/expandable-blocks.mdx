A full file is sometimes the clearest example, but a reader who scans the page does not need every line in view at once. The `expandable` attribute caps the block at a line count, with a fade at the cut and a button that reveals the rest.

export const basic = `
\`\`\`py title="report.py" expandable={8}
import csv
import sys
from collections import Counter
from pathlib import Path


def read_rows(path: Path) -> list[dict]:
    with path.open() as fh:
        return list(csv.DictReader(fh))


def summarise(rows: list[dict]) -> Counter:
    return Counter(row["status"] for row in rows)


def main() -> None:
    rows = read_rows(Path(sys.argv[1]))
    counts = summarise(rows)
    for status, n in counts.most_common():
        print(f"{status:<10} {n:>5}")


if __name__ == "__main__":
    main()
\`\`\`
`;

The block shows its first eight lines, faded at the bottom, with "Show all 24 lines" underneath. Selecting the button reveals the rest, and the button then reads "Show fewer lines".

## Syntax

| Syntax | Where | Effect |
|---|---|---|
| `expandable` | Fence line | Caps the block at the site default, 12 lines |
| `expandable={N}` | Fence line | Caps the block at `N` lines |
| `expandable=false` | Fence line | Turns off the `auto` option for the block |

## Behaviour

- The block shows the first `N` lines, with a fade over the last one.
- A bar under the code has a button, "Show all X lines", where X is the total. When the block is open, it reads "Show fewer lines".
- The block eases open and closed in 200 ms. The button stays under the pointer while the block closes. With reduced motion, the block opens and closes at once.
- A block collapses only if the collapse hides three lines or more. A block with eight lines and `expandable={7}` renders in full.
- Lines that [hidden lines](/starlight-codeblocks/features/hidden-lines/) remove do not count. In a block of 20 lines with `hidden={1-8} expandable={5}`, readers see 5 lines, and the button reads "Show all 12 lines".
- A block with Expressive Code's `collapse` attribute does not collapse, even with `expandable`, because its collapsed sections already shorten it.
- The collapsed lines use `hidden="until-found"` in browsers that support it. A reader who searches the page with Find still finds text inside them, and the block expands to show the match.
- A [line permalink](/starlight-codeblocks/features/line-permalinks/) to a collapsed line opens the block.
- Without JavaScript, the block renders in full, with no fade and no button.

## Options

<Options />

To show more lines in blocks with the bare `expandable` attribute, raise `lines`:

```js title="astro.config.mjs"
codeblocks({
  expandable: { lines: 20 },
});
```

### Make every long block expandable

The `auto` option makes every block with more lines than its value expandable, with no attribute. The block shows `lines` lines:

```js title="astro.config.mjs"
codeblocks({
  expandable: { lines: 12, auto: 30 },
});
```

With this configuration, a block of 31 lines or more shows its first 12 lines. Add `expandable=false` to the fence line of a block that must show in full. An `expandable={N}` attribute wins over the option.

`auto` skips blocks that have their own layout or their own controls:

- The variants of a [code switcher](/starlight-codeblocks/features/code-switcher/).
- Blocks with a [**Run in browser** button](/starlight-codeblocks/features/run-in-the-browser/).
- Blocks with Expressive Code's `collapse` attribute, from its collapsible sections plugin.
- Blocks in [`<CodeWalkthrough>`](/starlight-codeblocks/features/code-walkthrough/) and [`<Scrollycoding>`](/starlight-codeblocks/features/scrollycoding/), where each step must show every line.

## Examples

`expandable` with no number uses the site default:

export const siteDefault = `
\`\`\`yaml title=".github/workflows/ci.yml" expandable
name: CI

on:
  push:
    branches: [main]
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7

      - uses: actions/setup-node@v4
        with:
          node-version: 22

      - run: npm ci

      - run: npm test
\`\`\`
`;

## Limitations

- Expandable blocks print in full: the fade and the button do not appear on paper.

## Related

- [Hidden lines](/starlight-codeblocks/features/hidden-lines/): remove specific lines from view, instead of capping the block at a line count.
- [Focus](/starlight-codeblocks/features/focus/): keep every line in view, and blur the ones that do not matter.
