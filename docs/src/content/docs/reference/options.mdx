`codeblocks()` and `pluginCodeblocks()` take the same options object. A key with the type `false | object` takes `false` to turn the feature off, or an object with the settings below it. A key with the type `false` has no settings. The [configuration](/starlight-codeblocks/configuration/) page shows how to use them.
