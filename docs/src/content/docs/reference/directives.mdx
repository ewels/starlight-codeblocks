A directive goes in a comment, in the comment syntax of the language of the block. End-of-line directives apply to the line they are on. Own-line directives take a whole line and apply to the line below it. The [comment notation](/starlight-codeblocks/features/comment-notation/) page gives the rules that apply to every directive.
