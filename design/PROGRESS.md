### Known limits and accepted exceptions

- **Fade contrast.** Focus, code mentions and scrollycoding fade the lines that are not in focus below 4.5:1. De-emphasis is the point of these features; the accessibility page states the exception to WCAG 1.4.3.
- **Expressive Code `landmark-unique`.** Expressive Code's scrollable `pre` elements have `role="region"` with no label, so axe reports `landmark-unique` on pages with more than one such block. Upstream.
- **API link fetch cache never expires.** Bodies stay in `node_modules/.cache/starlight-codeblocks/`; delete the folder to fetch again.
- **Python adapter:** tuple targets other than the last (`json, a = …`) do not count as a rebinding; assignments are not followed. Built-ins do not link.
- **Colourised brackets and comment notation** use a language-agnostic scanner for strings and comments, so rare lines can be misread. Expressive Code has no token-scope API.
- **UI strings are English only.** No translation option.
- **Manual copy on blocks with fields:** a selection that goes past the block keeps the browser's own text.
- **CI needs the network:** the docs build fetches the Python `objects.inv` and, on a clean machine, the Inter fonts for the share cards, and one Pyodide e2e test loads Pyodide from jsDelivr.
- **starlight-pydocs** has no Node API, so the Python adapter reads its Griffe dump (ARCHITECTURE.md Q9).
