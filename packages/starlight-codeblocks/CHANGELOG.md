# Changelog

## 1.0.0

The first release. It adds these features to Starlight code blocks, on top of Expressive Code:

- Comment notation
- Focus
- Line states
- Inline callouts
- Annotations
- Footnotes
- Side annotations
- Hidden lines
- Smart shell copy
- Word-level diff
- Visible whitespace
- Colourised brackets
- Code links
- API auto-linking, with adapters for Python and Nextflow
- Expandable blocks
- Open in playground
- Code mentions
- Line permalinks
- Fill-in placeholders
- Code switcher
- Code walkthrough
- Scrollycoding
- Inline code highlighting
- Run in the browser, with a Pyodide runtime for Python
